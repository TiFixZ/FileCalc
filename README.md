# FileCalc

Считает выражения из input.txt и записывает ответы в output.txt.
Поддерживает +, -, *, / и дробные числа с точкой или запятой.

Собрать FileCalc.slnx в Visual Studio (.NET Framework 4.8).

```text
FileCalc.exe
FileCalc.exe a.txt b.txt
```

Каждое выражение на отдельной строке, например: `15 + 17 = ?`.
